# Research notebooks

Exploratory notebooks from the original work on the challenge. They are not part of the package, and CI does not lint or run them.

- `schools_tool_part1.ipynb` and `schools_tool_part2.ipynb` are early drafts of Part 1 and Part 2.
- `schools_tool_exploration.ipynb` profiles the dataset with pandas, numpy, seaborn and statsmodels. None of these are project dependencies.

The notebooks open `./input/school_data.csv`, so start Jupyter from the repository root rather than from this folder.
